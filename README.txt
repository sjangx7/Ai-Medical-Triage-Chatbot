Project Title: Explainable AI-Assisted Chatbot for Digital Medical Triage

Student Name: Sae Jang
Student ID: s2432618

Description:
This project implements a rule-based AI-assisted chatbot designed to classify medical urgency levels based on user symptoms.

Technologies Used:
- Node.js
- Express.js
- JavaScript (Frontend + Backend)

How to Run:
1. Install Node.js
2. Open terminal in project folder
3. Run: npm install
4. Run: node server.js
5. Open browser at: http://localhost:3000

Notes:
- This system is a research prototype and not intended for clinical use.
- No real patient data is stored.
